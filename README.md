# 数据结构可视化学习平台

基于《数据结构——用面向对象方法与 C++ 语言描述（第 3 版）》教材构建的可视化知识学习平台，将数据结构学科知识体系组织为可交互的「知识树 + 关联图谱 + 分类学习」三视图，并内置例题精讲与 AI 学习助手。

## ✨ 功能特性

- **知识树**：按「章节 → 模块 → 知识点」三级层级组织，支持展开浏览、点击查看详情、标记掌握进度
- **关联图谱**：力导向网状图展示知识点间的三类关系（前置依赖 / 延伸拓展 / 对比关联），节点带目录编号前缀、按章节分区着色、支持拖拽缩放
- **分类学习**：六个筛选维度（难度 / 重要性 / 类型 / 数据结构族 / 所属章节 / 是否含例题）组合过滤
- **例题精讲**：每个知识点配套例题（题目 / 思路分析 / 解题步骤 / 答案），重点内容含多道不同难度例题
- **代码解析**：核心知识点附完整 C++ 代码 + 逐行注释 + 串联知识点
- **AI 助手**：紧扣当前知识点上下文的问答（本地知识库引擎）

## 📊 内容规模

- 10 章 / 60 模块 / **136 个知识点**
- 137 条知识关联边
- 79 道文字例题 + 5 道代码例题 + 多道分层例题
- 91 个知识点含「概念辨析 / 应用场景 / 易错点 / 延伸阅读」深入理解
- 136 个知识点全含易错点速记与数据结构族分类

## 🚀 使用方法

纯静态页面，无需后端、无需联网（图表库已本地化）。

**方式一**：直接用浏览器打开 `index.html`

**方式二**：本地起一个静态服务器（推荐，避免部分浏览器 file:// 限制）：

```bash
# Python
python -m http.server 8642
# 然后访问 http://localhost:8642
```
